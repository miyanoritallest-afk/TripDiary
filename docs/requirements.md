## 1. システム概要・背景

### 1.1 目的

旅行体験を写真・地図ピンとともに共有できるSNS風アプリケーション。
他ユーザーの旅行投稿に「いいね」や「行きたい！」を押すことができ、
「行きたい！」を押すとAIキャラクター「ナビちゃん」との会話スレッドが自動生成され、旅行プランを気軽に相談できる。

### 1.2 差別化ポイント

| 機能 | 一般的な旅行SNS | TripDiary |
|------|---------------|-----------|
| 旅行投稿 | あり | あり |
| 写真スワイプ | あり | あり（最大6枚） |
| 地図ピン | 一部あり | あり（写真切り替えと連動） |
| いいね | あり | あり |
| 「行きたい！」ボタン | なし | **あり** |
| AI旅行プランナー | なし | **あり（ナビちゃん）** |
| 投稿からAIスレッド自動生成 | なし | **あり** |
| DM | あり | **なし** |
| 通知 | あり | **なし** |
| リツイート相当機能 | あり | **なし** |

## 3. 機能概要

### 3.1 機能スコープ（IN）

| カテゴリ | 機能 | 概要 |
|---------|------|------|
| 認証 | ユーザー登録 | メールアドレス・パスワードで新規アカウントを作成する |
| 認証 | ログイン | メールアドレス・パスワードで認証しセッションを開始する |
| 認証 | ログアウト | セッションを終了する |
| タイムライン | 全体タイムライン | 全ユーザーの投稿を新着順で表示する |
| タイムライン | フォロー中タイムライン | フォロー中のユーザーの投稿のみを新着順で表示する |
| 投稿 | 旅行投稿 | 写真（最大6枚）・本文・ハッシュタグ・地図ピンを投稿する |
| 投稿 | 投稿削除 | 自分の投稿を削除する |
| 写真 | 写真スワイプ | 投稿カード内の写真をスワイプで切り替える |
| 写真 | 地名バッジ表示 | 写真に対応した地名バッジを写真の下に表示し、写真切り替えと連動する |
| 地図 | 地図ピン表示 | 投稿詳細画面で地図上にピンを表示する |
| リアクション | いいね | 任意の投稿にいいねをする／取り消す |
| リアクション | 行きたい！ | 任意の投稿に「行きたい！」をする。ナビちゃんスレッドが自動生成される |
| フォロー | フォロー／フォロー解除 | 任意のユーザーをフォローする／解除する |
| ナビちゃん | スレッド一覧 | ナビちゃんとの会話スレッド一覧を表示する |
| ナビちゃん | スレッド自動生成 | 「行きたい！」を押した投稿からスレッドを自動生成し、導入メッセージを送る |
| ナビちゃん | スレッド手動作成 | ＋ボタンから新規スレッドを作成し、旅行プランを自由に相談する |
| ナビちゃん | チャット | Claude APIを用いたAIとの会話でプランを相談する |
| ナビちゃん | ユーザー好み記憶 | 会話内容からユーザーの好みを要約し、次回の会話に活用する |
| プロフィール | プロフィール表示 | アバター・ユーザー名・自己紹介・フォロー数・フォロワー数・投稿一覧を表示する |
| プロフィール | プロフィール編集 | アバター画像・ユーザー名・自己紹介を編集する |

### 3.2 機能スコープ（OUT）

- コメント機能
- リツイート・引用リツイート相当機能
- 通知機能
- DM（ダイレクトメッセージ）
- インプレッション（閲覧数）表示
- ハッシュタグ検索
- トレンド表示
- ブックマーク
- ユーザー検索

## 5. データ概要

主要エンティティは以下の通り。詳細は [データモデル・ER図](data-model.md) を参照。

| エンティティ | 概要 |
|-------------|------|
| users | ユーザー情報（認証情報・プロフィール・好みサマリー） |
| posts | 旅行投稿（本文・ハッシュタグ） |
| photos | 投稿に添付された写真（Supabase Storage URL・表示順） |
| pins | 写真に紐付く地図ピン（地名・緯度・経度） |
| likes | いいね（ユーザーと投稿の紐付け） |
| want_to_go | 行きたい！（ユーザーと投稿の紐付け） |
| follows | フォロー関係 |
| navi_threads | ナビちゃんとの会話スレッド |
| navi_messages | スレッド内の個々のメッセージ |
| user_preferences | ユーザーの旅行好みサマリー（ナビちゃん記憶） |

## 6. 技術・インフラ概要

| レイヤー | 技術 |
|---------|------|
| フロントエンド | Next.js 14 + TypeScript + Tailwind CSS |
| 認証 | NextAuth.js（メール＋パスワード） |
| データベース | PostgreSQL（Supabase） |
| ストレージ | Supabase Storage（写真） |
| 地図 | Leaflet.js + OpenStreetMap + Nominatim |
| AI | Claude API（Haiku for dev / Sonnet for prod） |
| ホスティング | Vercel |

詳細は [技術スタック](tech-stack.md) および [インフラ構成](infrastructure.md) を参照。
