# TripDiary 非機能要件

作成日: 2026-05-28
最終更新日: 2026-05-30

---

## 1. パフォーマンス

| 項目 | 要件 |
|------|------|
| タイムライン初期表示 | 2秒以内（通常のネットワーク環境） |
| APIレスポンス | 500ms以内（Claude API呼び出しを除く） |
| ナビちゃん応答 | ストリーミング表示で最初の文字が3秒以内に表示される |
| 写真アップロード | ユーザーへのプログレス表示を行いながら非同期で処理する |
| タイムライン取得件数 | 1回あたり最大20件（無限スクロール対応） |
| 写真1枚あたりのサイズ上限 | 10MB |

---

## 2. セキュリティ

| 項目 | 要件 |
|------|------|
| 認証方式 | NextAuth.js（セッションCookie）によるメール＋パスワード認証 |
| パスワード保存 | BCryptによるハッシュ化（平文保存禁止） |
| APIキー管理 | ANTHROPIC_API_KEY・AWSアクセスキー等はサーバーサイドのみで使用し、クライアントに露出させない |
| 入力バリデーション | フロントエンド・サーバーサイドの両方でバリデーションを実施 |
| XSS対策 | ReactのデフォルトエスケープによりXSSを防止。dangerouslySetInnerHTMLは使用しない |
| CSRF対策 | NextAuth.jsのCSRFトークンにより保護 |
| 認証が必要な操作 | 投稿・リアクション・ナビちゃん利用はすべてログイン必須。未認証リクエストはサーバーサイドで拒否（401） |
| 権限チェック | 他ユーザーの投稿削除はサーバーサイドで拒否（403） |
| AWS S3 / ローカルストレージ | 写真アップロードはサーバーサイド（Route Handler）のみ経由。クライアントからストレージへの直接アップロードは禁止 |

---

## 3. 対応ブラウザ・デバイス

| 項目 | 要件 |
|------|------|
| 対応ブラウザ | Google Chrome（最新版）、Microsoft Edge（最新版）、Safari（最新版）、Firefox（最新版） |
| 対応デバイス | PC・スマートフォン両対応。モバイルファーストのスタイリングで実装済み |
| 推奨画面幅 | 390px（スマートフォン）〜 1280px（PC）。最大コンテンツ幅は `max-w-xl`（576px）でセンタリング |
| スマートフォン対応 | 実装済み（BottomTab・PostCard・モーダル等がモバイルレイアウトに対応） |

---

## 4. データ整合性

| 項目 | 要件 |
|------|------|
| DBマイグレーション | Prisma Migrateによりスキーマ変更を管理する |
| 投稿削除時のカスケード | 投稿削除時に関連する写真・ピン・いいね・行きたい！・ナビちゃんスレッドを連動削除する |
| いいねの重複防止 | DBのUNIQUE制約 `(post_id, user_id)` で重複いいねを防ぐ |
| 行きたい！の重複防止 | DBのUNIQUE制約 `(post_id, user_id)` で重複行きたい！を防ぐ |
| フォローの重複防止 | DBのUNIQUE制約 `(follower_id, following_id)` で重複フォローを防ぐ |
| 自己フォロー禁止 | DBのCHECK制約 `follower_id <> following_id` で自己フォローを防ぐ |
| 写真の順番保証 | `display_order` カラムで表示順を厳密に管理する |

---

## 5. テスト

プロトタイプフェーズでは自動テストよりも動作確認を優先する。本格実装フェーズでテスト戦略を策定する。

| テスト種別 | 対象 | 方針 |
|----------|------|------|
| 手動テスト | 全機能 | 開発者による動作確認 |
| 単体テスト | ユーティリティ関数・APIルート | Vitest（本格実装フェーズで追加） |
| E2Eテスト | 主要ユーザーフロー | Playwright（本格実装フェーズで追加） |

---

## 6. アクセシビリティ

| 項目 | 要件 |
|------|------|
| キーボード操作 | 主要な操作（ログイン・投稿・いいね）はキーボードで実行できる |
| フォーカス管理 | フォーカスが視覚的に判別できるようにする |
| 色コントラスト | WCAG 2.1 AA 基準（コントラスト比 4.5:1 以上）を目標とする |
| 画像のalt属性 | 投稿写真にはalt属性を設定する（地名や投稿者名を利用） |

---

## 7. 可用性

| 項目 | 要件 |
|------|------|
| ホスティング可用性 | AWS EC2に依存 |
| DB可用性 | AWS RDS（PostgreSQL）のマネージドサービスに依存 |
| Claude API障害時 | ナビちゃんが応答できない旨のメッセージを表示し、アプリ全体の利用は継続できる。フォールバックメッセージを用意済み |
| バックアップ | AWS RDSの自動バックアップ機能に依存 |
