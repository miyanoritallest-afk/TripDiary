# TripDiary 画面設計書

作成日: 2026-05-28
最終更新日: 2026-05-30

---

## 1. 画面一覧

| No | 画面名 | 認証要否 | 概要 |
|----|--------|---------|------|
| 1 | ログイン画面 | 不要 | メールアドレス・パスワードでログインする |
| 2 | 会員登録画面 | 不要 | 新規アカウントを作成する |
| 3 | タイムライン画面 | 必要 | 全体／フォロー中の投稿をタブ切り替えで表示する |
| 4 | 投稿詳細画面 | 必要 | 投稿の詳細と地図ピンを表示する |
| 5 | 投稿作成画面 | 必要 | 写真・本文・ハッシュタグ・地図ピンを投稿する |
| 6 | ナビちゃんスレッド一覧画面 | 必要 | ナビちゃんとの会話スレッド一覧を表示する |
| 7 | ナビちゃんチャット画面 | 必要 | ナビちゃんと旅行プランを相談する |
| 8 | プロフィール画面 | 必要 | ユーザーのプロフィールと投稿一覧を表示する |
| 9 | プロフィール編集画面 | 必要（本人のみ） | アバター・ユーザー名・自己紹介を編集する |

## 2. 共通レイアウト

### 2.1 BottomTab（ログイン後全画面）

```
┌─────────────────────────────────────────────────────────┐
│                     コンテンツエリア                      │
│                                                         │
└─────────────────────────────────────────────────────────┘
┌────────┬────────┬──────────┬────────┬────────┐
│ 🌍     │ 👥     │  ＋記録  │ ➤相談  │ 👤     │
│タイムライン│フォロー中│（投稿）  │（ナビ） │プロフィール│
└────────┴────────┴──────────┴────────┴────────┘
```

- 左2つ：タイムライン・フォロー中タブ（通常タブ、アクティブインジケーター付き）
- 中央2つ：投稿ボタン（オレンジ円形）・相談ボタン（ティール円形）。タブより浮き上がったFABスタイル
- 右2つ：ナビちゃん・プロフィールタブ（通常タブ、アクティブインジケーター付き）

| 要素 | 遷移先 |
|------|--------|
| タイムラインタブ | 全体タイムライン画面（`/timeline`） |
| フォロー中タブ | フォロー中タイムライン画面（`/following`） |
| 記録ボタン（＋） | 投稿作成モーダルを表示（現在のページ上でモーダルを開く） |
| 相談ボタン（➤） | ナビちゃん新規スレッド作成モーダルを表示（`/navi?new=1`） |
| ナビちゃんタブ | ナビちゃんスレッド一覧画面（`/navi`） |
| プロフィールタブ | プロフィール画面（`/profile`） |

### 3.5 投稿作成（モーダル）

タイムライン・フォロー中画面のBottomTab「記録」ボタンから開くモーダル（独立した画面・ルートではない）。

```
┌──────────────────────────────────────────────────────┐
│  キャンセル          旅を記録する          [投稿する] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  写真（最大6枚）                            0/6      │
│  [写真1] [写真2] [＋追加]                            │
│  ※写真サムネイル右下の📍ボタンでピンを設定できる     │
│                                                      │
│  [旅の感想を書こう...                              ] │
│                                                      │
│  [#タグを追加]  [追加]                               │
│  #京都旅行 ×   #紅葉 ×                              │
│                                                      │
└──────────────────────────────────────────────────────┘
```

| 要素 | 仕様 |
|------|------|
| 写真追加 | 最大6枚。選択と同時にサーバーへアップロードが始まる（非同期）。アップロード完了後にピン設定が可能になる |
| ピン設定 | 写真サムネイル右下の📍ボタンをタップ → 地名入力・検索（Nominatim）→ 選択で写真にピンを紐付け |
| 本文 | 任意 |
| ハッシュタグ | 任意。Enterまたは「追加」ボタンで追加。「#」は自動除去 |
| 投稿するボタン | 写真が1枚以上必要（写真なし・本文のみでは投稿不可） |

## 4. エラーハンドリング

### 4.1 投稿フォーム

| エラーケース | 対応 |
|-------------|------|
| 写真が未選択かつ本文が空 | 「写真または本文を入力してください」を表示 |
| 写真が7枚以上 | 「写真は最大6枚まで添付できます」を表示 |
| 写真アップロード失敗 | 「写真のアップロードに失敗しました」を表示 |

### 4.2 認証

| エラーケース | 対応 |
|-------------|------|
| ログイン失敗 | 「メールアドレスまたはパスワードが正しくありません」 |
| メールアドレス重複 | 「このメールアドレスはすでに使用されています」 |
| パスワード不一致 | 「パスワードが一致しません」 |

### 4.3 共通

| エラーケース | 対応 |
|-------------|------|
| 未認証でのアクセス | ログイン画面へリダイレクト |
| 存在しないリソース | 「ページが見つかりません（404）」を表示 |
| サーバーエラー | 「エラーが発生しました。しばらく時間をおいて再試行してください」を表示 |
| Claude APIエラー | 「ナビちゃんとの通信に失敗しました。再度お試しください」を表示 |

## 5. 画面遷移図

```mermaid
stateDiagram-v2
    [*] --> ログイン画面

    ログイン画面 --> タイムライン画面 : ログイン成功
    ログイン画面 --> 会員登録画面 : 新規登録リンククリック

    会員登録画面 --> タイムライン画面 : 登録成功
    会員登録画面 --> ログイン画面 : ログインリンククリック

    タイムライン画面 --> 投稿詳細画面 : 投稿カードクリック
    タイムライン画面 --> プロフィール画面 : アバター／ユーザー名クリック
    タイムライン画面 --> ナビちゃんチャット画面 : 「行きたい！」ボタン押下
    タイムライン画面 --> 投稿作成画面 : 投稿作成ボタン押下

    投稿詳細画面 --> タイムライン画面 : 戻るボタン
    投稿詳細画面 --> プロフィール画面 : アバター／ユーザー名クリック

    ナビちゃんスレッド一覧画面 --> ナビちゃんチャット画面 : スレッドカードクリック
    ナビちゃんスレッド一覧画面 --> ナビちゃんチャット画面 : ＋ボタン（新規作成）
```
